================================================
RSRP Improvement Automated Pipeline - Setup Guide
================================================

1. INSTALL DEPENDENCIES
-----------------------
You will need Python installed on your machine. Open your command prompt or terminal in this folder and run:
    pip install -r requirements.txt


2. RUN THE PIPELINE
-------------------
All input data has already been provided in the "Input_Data" folder! 

To do anything (run the pipeline, update maps, open dashboard, export PPTX), simply run the master hub script:

    python run.py

This will open an interactive menu where you can choose exactly what you want to do just by typing a number!
